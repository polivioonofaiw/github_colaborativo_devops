# Tags

## Flujo de Tags
1. Identificar la versión que se desea etiquetar
2. Verificar que los cambios estén validados
3. Crear el tag correspondiente utilizando la nomenclatura definida para el proyecto
4. Asociar el tag al commit correspondiente
5. Publicar el tag en el repositorio remoto

## Buenas prácticas
- Utilizar una nomenclatura consistente para los tags
- Verificar que el tag apunte al commit correcto
- Evitar reutilizar tags existentes
- Mantener los tags alineados con las Releases publicadas en GitHub
