# Releases

## Flujo de Releases
1. Crear rama `release/x.y.z`
2. Ejecutar pruebas y validaciones
3. Generar el tag correspondiente
4. Publicar la versión en GitHub

## Buenas prácticas
- Mantener changelog actualizado
- Revisar issues cerrados
- Validar CI/CD antes de publicar
